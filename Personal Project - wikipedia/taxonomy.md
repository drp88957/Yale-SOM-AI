# Taxonomy — Allowed Tags

Pages may only use the tags below. This keeps the sidebar small and stops near-duplicate tags.
`build.py` warns about any tag that isn't listed here. Format: `- slug — Label`.
Situations and concepts with no stories yet stay hidden in the UI.
