# My Library — Books Read Completely

The source list for the wiki. Every page in the wiki must trace back to one of these books.
Books are grouped onto **shelves** of similar books. The `## ` headings below become the shelves in the UI.

Notes on the original list:
- *David and Goliath* appeared twice (#10 and #44), so it's listed once here.
- *The Data Detective* (US title) and *How to Make the World Add Up* (UK title) are the **same book** by Tim Harford. It's kept as one entry.
- *The Goal 2* is assumed to be Goldratt's *It's Not Luck*. *Currency Wars* is assumed to be James Rickards. Correct these if they're wrong.
